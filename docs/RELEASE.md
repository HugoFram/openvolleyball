# Open Volleyball 2.0.0

Version officielle pour Windows x64, basée sur la version alpha.10 acceptée.

Télécharger **Open-Volleyball-2.0.0-Windows.zip**, décompresser puis lancer
**Open-Volleyball-2.0.0-Windows.exe**. Le ZIP contient le guide et les exemples.
L’exécutable seul fonctionne aussi sans installation. Aucun compte ni connexion
Internet n’est nécessaire à l’utilisation. Le programme n’est pas signé par un
certificat commercial.

- Tournoi complet : inscriptions, groupes successifs, qualification Principale /
  Consolante, progression commune, tableau final interactif et classement.
- Feuilles A4, logo et site, affichage PDF, impression individuelle ou par phase.
- Import local de scores manuscrits avec relecture et validation.
- Backup complet avec nom et destination au choix. Export des joueurs en CSV
  (virgule ou point-virgule) et Excel `.xlsx`.

**La transcription des inscriptions manuscrites reste expérimentale.** Le lecteur
intégré fonctionne hors ligne. Le pack avancé facultatif déjà installé reste
compatible ; il n’est pas nécessaire de le réinstaller. Chaque proposition doit
être relue. Les modèles et les résultats sont inchangés depuis la version acceptée.

Avant d’ouvrir un tournoi v1 avec v2, conserver une copie complète : le format v2
n’est pas lisible par v1. Les exemples synthétiques et l’historique Git sont conservés.

Les empreintes SHA-256 des téléchargements figurent dans **SHA256SUMS-2.0.0.txt**.

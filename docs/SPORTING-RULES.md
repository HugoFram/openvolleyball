# Décisions sportives

L’organisateur confirme cette interprétation dans **Règlement** avant le premier groupe. Les phases conservent leur propre copie des règles.

| Sujet | Proposition implémentée |
|---|---|
| Score | Seuil 21/25 ; écart de 2 par défaut, choix de 1 avant compétition. Prolongation sans plafond, arrêt au premier écart requis. Avec seuil 25/écart 2 : 25–0 et 30–28 valides ; 30–20 invalide. |
| Dans un groupe | Victoire 2 points, défaite 1 ; puis différence brute. Les égalités restantes partagent le rang. Pas de confrontation directe ni d’ordre alphabétique implicite. |
| Entre groupes | Par défaut rang de groupe, points de classement/match, différence/match. Autre choix avant compétition : omettre la priorité au rang. Les calculs comparent des produits entiers sans arrondi. |
| Égalités | Répartition : décision seulement si un bloc traverse la limite. Finale : les égalités affectant les têtes de série sélectionnées sont pertinentes. Sélecteurs nominatifs, validation d’un ordre complet, contexte propre à la phase et au nombre de qualifiés. |
| Participants ultérieurs | Toutes les équipes actives de la branche pour les nouveaux groupes ; les meilleures de sa dernière phase pour la finale. Les retraits concernent uniquement les phases futures. |
| Tableaux | 2–64 participants ; puissance de deux supérieure ; exemptions aux meilleures têtes de série ; répartition conventionnelle récursive. 4/8/16 vérifiés de bout en bout. 32/64 utilisent le même moteur sans parcours manuel dédié. |
| Cibles des tours | 21 pour les tours précoces, 25 pour finale/Petite finale par défaut ; choix 21/25 à la création ; pas de changement rétroactif. |
| Arbitrage | Équipe au repos si disponible. À cinq/deux terrains, elle supervise les deux matchs synchronisés. Sinon « Arbitre externe à désigner », modifiable dans les détails. |
| Forfaits | Aucun forfait nouveau automatique ou bouton de forfait. Le modèle accepte un résultat historique marqué, mais aucune fidélité à un ancien format non fourni n’est revendiquée. |
| Corrections | Chemin explicite, conséquences annoncées, état antérieur archivé et sauvegardé. Les descendants d’une phase de groupes corrigée sont conservativement retirés et archivés. |

L’ordre indicatif d’un bloc statistiquement égal n’est pas un départage. Un choix humain est requis pour tout ordre ayant un effet sportif. Les décisions de démonstration des exemples sont synthétiques.

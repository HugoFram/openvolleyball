# Décisions sportives

Règles fixes depuis la version 1.1, conformément aux changements demandés. Aucun onglet de configuration du règlement n’est nécessaire.

| Sujet | Interprétation implémentée |
|---|---|
| Score | Seuil 21/25 ; écart toujours de 2, sans plafond. Arrêt au premier écart requis après le seuil. Avec seuil 25 : 25–0 et 30–28 valides ; 25–24 et 30–20 invalides. |
| Classement de groupe et général | Victoires / matchs joués, puis différence de points / matchs joués. Comparaison exacte par produits entiers ; les arrondis affichés ne décident pas du classement. Les points 2/1 sont conservés comme information historique et ne servent pas au départage. |
| Égalités | Rang partagé tant qu’aucun choix sportif ne l’exige. Qualification : seulement les blocs traversant la limite. Finale : ceux affectant les têtes de série. Nouveaux groupes : ceux répartis entre destinations différentes. Sélecteurs nominatifs numérotés, ordre complet et distinct, décision enregistrée pour le contexte concerné. Aucun départage alphabétique ou par confrontation directe. |
| Groupes initiaux | Équilibrage d’après la moyenne des niveaux des joueurs : N=3, R=2, D=1, U=0. Les valeurs sont stockées en arrière-plan ; la saisie présente les lettres. |
| Groupes ultérieurs | Toutes les équipes actives de la branche, classées selon les résultats de leur dernière phase de groupes. Répartition en serpent entre groupes, en respectant leurs capacités ; les équipes d’un bloc égal qui change de destination sont départagées manuellement. Les cartes présentent le rang précédent, conservé avec la phase. Les échanges manuels restent possibles avant confirmation. |
| Effectifs | Nouvelle création ou modification : exactement trois ou quatre joueurs nommés. Les anciennes fiches d’un autre effectif restent lisibles mais doivent être régularisées pour être enregistrées. |
| Terrains | Un terrain par groupe de trois/quatre ; un ou deux pour un groupe de cinq. Les anciennes phases déjà confirmées conservent leur calendrier. |
| Participants | Les retraits excluent uniquement les prochaines phases, sans réécrire l’historique. |
| Tableaux | 2–64 participants ; puissance de deux supérieure ; exemptions aux meilleures têtes de série ; répartition récursive conventionnelle. 4/8/16 vérifiés de bout en bout. |
| Matchmaking manuel | Avant le premier résultat de la phase finale, deux équipes du premier tour peuvent échanger leurs positions. Les places d’exemption sont fixes ; leurs bénéficiaires peuvent être échangés. Les rangs précédents et la qualification ne changent pas. Après le premier résultat ou forfait enregistré, le tableau est verrouillé. |
| Cibles des tours | 21 pour les tours précoces, 25 pour finale/Petite finale par défaut ; choix 21/25 à la création, sans changement rétroactif. |
| Arbitrage | Groupe : équipe au repos si disponible ; à cinq/deux terrains elle supervise les deux matchs synchronisés. Sinon arbitre externe explicite. Finale : arbitre facultatif, champ vide par défaut et sur les feuilles. |
| Feuilles | Préparation automatique pour les groupes confirmés et toutes les rencontres finales, même en attente de participants. Actualisation automatique des participants, terrains et arbitres après enregistrement ; afficher/imprimer utilise la dernière version enregistrée. |
| Compatibilité 1.0 | Résultats, effectifs, calendriers et répartitions déjà enregistrés conservés. Les nouvelles vues/décisions utilisent le classement fixe ; les nouveaux scores/corrections exigent deux points. Un score historique à un point conserve sa règle d’origine. |
| Forfaits | Aucun nouveau forfait automatique ou bouton dédié. Le modèle accepte un résultat historique marqué ; aucun ancien format externe non fourni n’est supposé. |
| Corrections | Conséquences annoncées, état antérieur archivé et sauvegardé. Les descendants d’une phase de groupes corrigée sont conservativement retirés du parcours actif. |

L’ordre indicatif d’un bloc statistiquement égal ne constitue pas un départage. Les décisions des exemples sont synthétiques ; les dossiers d’exemples d’origine ne sont pas réécrits par cette mise à jour.
